GSV-Jakarta: auditing a street-imagery pipeline LSE

52.7%of people actually found
2,563people hand-labelled
1.4Mimages segmented

On an FCDO-funded LSE project, a team pipeline detected and classified pedestrians in 1M+ Google Street View images of Jakarta. I designed its only blind, probability-weighted ground-truth sample and measured what the model really found.

  • Hand-labelled 2,563 people in CVAT without seeing the model's output (κ = 0.85 intra-annotator)
  • The pipeline counted 52.7% of people present (95% CI 46.6–58.9), with 21.5% false detections, even though its aggregate ratios looked correct
  • Found three silent failures: a wrong model loading without an error, an index collapsing 347,237 files to 39,988, and 68.8% duplicate rows
  • Delivered a 1.4M-image semantic segmentation dataset with 28 categories

YOLOv8 at the edge: Python → C++ → INT8 on Snapdragon

3.5×smaller model
1.5×faster on phone NPU
0.0C++ vs Python difference

I wrote YOLOv8 inference by hand (letterbox, tensor layout, box decoding, NMS), ported it to C++, then quantised it for a phone NPU.

  • The C++ port matches Python bit-for-bit (max difference 0.0). All 26 unit tests pass, with no sanitizer errors.
  • C++ pre-processing is about 2.8× faster than Python. Inference time is the same, because both use the same engine.
  • The first INT8 model scored mAP 0. I traced this to every output score rounding to zero, kept the decode step in FP32, and recovered the accuracy.
  • Result: 3.5× smaller (12.2 → 3.5 MB), about 1.5× faster on the Snapdragon 8 Gen 3 NPU (3.34 → 2.20 ms), with mAP50-95 going from 0.381 to 0.366.

Camera calibration lab

1.62 → 0.82px reprojection error
±0.26%focal-length stability
57 → 85%image coverage

Calibrating a phone camera with a ChArUco board shown on a monitor. This is the first module of a 3D perception portfolio.

  • Residual plots showed the monitor's moiré pattern was biasing corner detection
  • A light blur before detection cut RMS reprojection error from 1.62 to 0.82 px, while keeping all 1,330 corners
  • Bootstrapping 50 random image subsets showed the focal length is stable to ±0.26%
  • A coverage map showed blind spots at the image edges. Extra edge shots raised coverage from 57% to 85%.
